# 콘솔 환경에서 구현한 월남뽕 카드 게임
- C#으로 구현한 Windows Console 기반 카드 베팅 게임입니다.

## 주요 기능
- 52장 카드 덱 생성 및 셔플 (Fisher-Yates Shuffle)
- 카드 3장을 이용한 승패 판정 로직
- 첫 번째 카드(A)와 세 번째 카드(C) 사이에 두 번째 카드(B)가 위치하면 승리
- 베팅 시스템 (최소 1000원)
- 승리 시 베팅 금액 획득, 패배 시 베팅 금액 차감
- 카드 소진 또는 자금 부족 시 게임 종료
- 현재 자금 및 사용된 카드 수 출력

## 게임 방식
- 매 라운드마다 카드 3장이 공개됩니다.
- 플레이어는 베팅 금액을 입력합니다.
- 두 번째 카드가 첫 번째 카드와 세 번째 카드 사이 값이면 승리합니다.
- 결과에 따라 자금이 증가하거나 감소합니다.

## 실행 환경
- C#
- Windows Console
- Visual Studio 2022

## 실행 방법
- Visual Studio 2022에서 프로젝트를 열고 빌드 후 실행합니다.
